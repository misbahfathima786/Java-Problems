# 🧮 Java Calculator

A simple command-line calculator developed in Java.

## 📌 Description

This program performs basic arithmetic operations based on the user's input.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Handles division by zero

## 🛠️ Concepts Used

- Java
- Scanner Class
- Switch Statement
- Conditional Statements
- User Input

## 🔢 Sample Input

```
Enter First Operand.
15
Enter Operator.
+
Enter Second Operand.
25
```

## 📷 Sample Output

```
15 + 25 = 40.
```
