# 🌟 Functions (2) - Java Programs

This folder contains 10 beginner-friendly Java programs that demonstrate the use of **functions (methods)**, **loops**, **conditional statements**, and **recursion**. These programs help in understanding how to write reusable code and solve basic programming problems in Java.

---

## 📚 Programs Included

### 1. Average of Three Numbers
Calculates the average of three user-entered numbers using a user-defined function.

**Concepts Used:**
- Methods (Functions)
- Parameters and Return Value
- Scanner Class

---

### 2. Sum of Odd Numbers
Finds the sum of all odd numbers from **1 to n** using a function.

**Concepts Used:**
- Methods
- Loops
- Conditional Statements

---

### 3. Greatest of Two Numbers
Determines the greater of two numbers using a user-defined function.

**Concepts Used:**
- Methods
- Ternary Operator
- Scanner Class

---

### 4. Circumference of a Circle
Calculates the circumference of a circle using the given radius.

**Concepts Used:**
- Methods
- Mathematical Formula
- Scanner Class

---

### 5. Check Adult Eligibility
Checks whether a person is eligible to vote based on their age.

**Concepts Used:**
- Methods

- Scanner Class

### 6. Infinite Do-While Loop
Demonstrates an infinite `do-while` loop by continuously printing a message.

**Concepts Used:**
- Do-While Loop

### 7. Count Positive, Negative, and Zero

**Concepts Used:**
- Do-While Loop

### 8. Power of a Number
Calculates the power of a number using a user-defined function.

**Concepts Used:**
- Methods
- Loops

### 9. Greatest Common Divisor (GCD)
Finds the GCD of two numbers using a recursive function.
