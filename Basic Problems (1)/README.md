# 🌟 Java Basic Problems (1)

This folder contains **12 beginner-friendly Java programs** that cover fundamental programming concepts such as conditional statements, loops, methods, number operations, and basic problem-solving techniques. These programs are ideal for beginners to strengthen their understanding of core Java programming.

# 1. Positive or Negative Number

## 📝 Description
This program accepts an integer from the user and determines whether it is positive, negative, or zero.

### ✨ Features
- Accepts user input
- Identifies positive, negative, and zero values
- Uses the ternary operator and conditional statements

### 💻 Concepts Used
- Java
- Scanner Class
- Conditional Statements
- Ternary Operator

### 📥 Sample Input
```

```

### 📤 Sample Output
```

```
