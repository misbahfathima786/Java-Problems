# 🔍 Month Name Finder

A simple Java program that displays the corresponding month name based on the number entered by the user.

## 📌 Description

The user enters a number between **1 and 12**, and the program prints the corresponding month name. If the input is outside this range, an error message is displayed.

## ✨ Features

- Accepts month number as input
- Displays the corresponding month name
- Handles invalid input

## 🛠️ Concepts Used

- Java
- Scanner Class
- Switch Statement
- User Input

## 🔢 Sample Input

```
Enter a number for month.
8
```

## 🗓️ Sample Output

```
August.
```
