# 🌟 Java Arrays Programs

This folder contains **5 beginner-friendly Java programs** that demonstrate the fundamentals of **Arrays** in Java. These programs cover one-dimensional and two-dimensional arrays, including input/output, finding maximum and minimum values, checking array order, matrix transpose, and spiral traversal.

---

# 1. Input and Display String Array

## 📝 Description
This program accepts multiple string values from the user, stores them in an array, and displays all the entered strings.

### ✨ Features
- Accepts string inputs
- Stores data in a one-dimensional array
- Displays all array elements

### 💻 Concepts Used
- Java
- Scanner Class
- One-Dimensional Arrays
- Loops

### 📥 Sample Input
```
Enter the size of an array : 3
Java
Python
C++
```

### 📤 Sample Output
```
Java Python C++
```

# 2. Find Maximum and Minimum Element in an Array

## 📝 Description
This program finds the maximum and minimum values from a predefined integer array using `Integer.MIN_VALUE` and `Integer.MAX_VALUE`.

### ✨ Features
- Finds the largest element
- Finds the smallest element
- Uses enhanced for-loop

### 💻 Concepts Used
- Java
- Arrays
- Enhanced For Loop
- Integer.MIN_VALUE
- Integer.MAX_VALUE

### 📥 Sample Input
```
Predefined Array:
-2 10 18 17 -4
```

### 📤 Sample Output
```
Maximum value in an array is : 18
Minimum value in an array is : -4
```

# 4. Transpose of a Matrix

## 📝 Description
This program accepts a two-dimensional array (matrix) from the user, displays the original matrix, and prints its transpose.

### ✨ Features
- Accepts matrix input
- Displays the original matrix
- Prints the transpose of the matrix

### 💻 Concepts Used
- Java
- Scanner Class
- Two-Dimensional Arrays
- Nested Loops
- Matrix Operations

### 📥 Sample Input
```
Enter the number of rows : 2
Enter the number of columns : 3
1 2 3
4 5 6
```

### 📤 Sample Output
```
Given array
1 2 3
4 5 6

Transpose of given array
1 4
2 5
3 6
```

This program accepts a matrix from the user and prints its elements in spiral order.

### ✨ Features

- Prints matrix elements in spiral order

### 💻 Concepts Used
- Java
- Scanner Class
- Two-Dimensional Arrays
- Nested Loops
- Spiral Traversal Algorithm

### 📥 Sample Input
```
Enter the number of rows : 3
Enter the number of columns : 3

```
