# 📘 Java Functions Programs

This folder contains **3 beginner-friendly Java programs** that demonstrate the use of **functions (methods)**. Each program performs a different task using user input and method calls.

---

## 📌 Programs Included

### 1. Prime Number Check

#### 📝 Description
This program checks whether a given number is **Prime** or **Not Prime** using a separate method.

#### ✨ Features
- User-defined input
- Uses a function (`primeNumber()`)
- Efficient prime checking (`i * i <= n`)
- Displays whether the number is prime or not

#### 💻 Concepts Used
- Java
- Functions (Methods)
- Scanner Class
- Loops
- Conditional Statements

#### 📥 Sample Output

**Input**
```text
Enter a number: 17
```

**Output**
```text
Prime number.
```

### 3. Multiplication Table

#### 📝 Description
This program prints the multiplication table of a given number from **1 to 10** using a separate method.

#### ✨ Features
- User-defined input
- Uses a function (`printTable()`)
- Prints multiplication table up to 10

#### 💻 Concepts Used
- Java
- Functions (Methods)
- Scanner Class
- For Loop
- Arithmetic Operations

#### 📥 Sample Output

**Input**
```text
Enter a number: 5
```

**Output**
```text

5x2=10
5x3=15
5x4=20
5x5=25
5x6=30
5x7=35
5x8=40
5x9=45
5x10=50
```
