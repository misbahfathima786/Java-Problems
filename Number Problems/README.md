# Java Number Programs

This repository contains simple Java programs based on basic programming concepts.

## Programs Included

### 1. Prime Number

* Accepts a number from the user.
* Checks whether the number is prime or not.
* Uses an optimized approach by checking divisibility only up to the square root of the number.

### 2. Even Numbers

* Accepts a number from the user.
* Prints all even numbers from 1 up to the given number.

## 🛠️ Concepts Used

* Java
* Scanner Class
* `for` Loop
* `if` Statement
* Modulus (`%`) Operator
* Boolean Variables
* Basic Number Logic


## 📷 Sample Output

### Prime Number

**Input:**

```text
Enter a number : 17
```

**Output:**

```text
Prime number.
```

**Input:**

```text
Enter a number : 18
```

**Output:**

```text
Not a Prime number.
```
