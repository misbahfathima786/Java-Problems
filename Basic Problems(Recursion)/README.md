# Basic Problems – Recursion

This folder contains **9 basic problems implemented using recursion in Java**.

These programs are designed to understand the fundamental concepts of recursion, including **base cases, recursive calls, arrays, strings, numbers, and backtracking**.

## 📂 Problems Included

| No. | Problem                           | File               |
| --- | --------------------------------- | ------------------ |
| 1   | Power of a Number                 | `Power.java`       |
| 2   | Prime Number                      | `Prime.java`       |
| 3   | Find Largest Element in an Array  | `Largest.java`     |
| 4   | Find Smallest Element in an Array | `Smallest.java`    |
| 5   | Reverse a Number                  | `Reverse.java`     |
| 6   | Find HCF of Two Numbers           | `HCF.java`         |
| 7   | Find LCM of Two Numbers           | `LCM.java`         |
| 8   | Find Length of a String           | `Length.java`      |
| 9   | Generate Permutations of a String | `Permutation.java` |

## 1. Power of a Number

Finds the power of a number using recursion.

### Example

```text
Input:
Base = 2
Exponent = 5

Output:
Power of a number = 32
```

### Concept Used

* Recursion
* Base case
* Multiplication through recursive calls

## 🎯 Purpose

The purpose of these programs is to build a strong foundation in **recursion using Java** by solving simple problems step by step.

These problems help in understanding how a problem can be divided into smaller subproblems and solved using **recursive calls and base cases**.
