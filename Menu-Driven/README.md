# Student Marks Evaluation (Java)

## 📌 Description

A simple menu-driven Java program that uses a **do-while loop** to repeatedly accept a student's marks until the user chooses to exit. The program evaluates the marks and displays an appropriate message based on the given criteria.

## ✨ Features

* Menu-driven program
* Uses a `do-while` loop
* Accepts marks between **0 and 100**
* Validates invalid marks
* Displays messages based on the marks entered

## 📋 Marks Evaluation

| Marks    | Output               |
| -------- | -------------------- |
| 90 – 100 | This is Good         |
| 60 – 89  | This is also Good    |
| 0 – 59   | This is Good as well |
| Invalid  | Invalid marks        |

## 🛠️ Concepts Used

* Java
* Scanner Class
* `if-else` Statements
* `do-while` Loop
* Input Validation
