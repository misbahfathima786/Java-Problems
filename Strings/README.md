# 🌟 Java Strings Programs

This folder contains **3 beginner-friendly Java programs** that demonstrate the use of **Strings** in Java. These programs perform common string operations such as calculating string lengths, replacing characters, and extracting usernames from email addresses.

---

# 1. Total Length of Strings in an Array

## 📝 Description
This program accepts multiple strings from the user, stores them in an array, displays the length of each string, and calculates the total length of all the strings.

### ✨ Features
- Accepts multiple string inputs
- Stores strings in an array
- Displays the length of each string
- Calculates the total length of all strings

### 💻 Concepts Used
- Java
- Scanner Class
- Arrays
- Strings
- Loops
- `length()` Method

### 📥 Sample Input
```
Enter the size of an array : 3
Java
Programming
Language
```

### 📤 Sample Output
```
Length of Java is : 4
Length of Programming is : 11
Length of Language is : 8
Total Length of the strings in array is : 23
```

---

# 2. Replace Character in a String

## 📝 Description
This program accepts a string from the user and replaces every occurrence of the character **'e'** with **'i'**, then displays the modified string.

### ✨ Features
- Accepts a string as input
- Replaces all occurrences of 'e' with 'i'
- Creates a new modified string
- Displays the resultant string

### 💻 Concepts Used
- Java
- Scanner Class
- Strings
- Character Manipulation
- Loops

### 📥 Sample Input
```
Enter a string : welcome
```

### 📤 Sample Output
```
Resultant String after replacement of character = wilcomi
```

---

# 3. Extract Username from an Email

## 📝 Description
This program accepts an email address from the user and extracts the username by reading characters until the **'@'** symbol is encountered.

### ✨ Features
- Accepts an email address
- Extracts the username
- Uses character-by-character traversal
- Displays the extracted username

### 💻 Concepts Used
- Java
- Scanner Class
- Strings
- Character Traversal
- Loops

### 📥 Sample Input
```
Enter an Email : john123@gmail.com
```

### 📤 Sample Output
```
Username = john123
```

## 🎯 Learning Outcomes

After completing these programs, you will understand:
- How to work with Strings in Java
- How to calculate the length of strings
- How to traverse strings using loops
- How to replace characters in a string
- How to extract specific parts of a string
- Practical applications of string manipulation in Java
